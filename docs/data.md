# Data versions

## v0.1 model training: 7,000 examples

This is the corpus that trained FormoSync E4B's Round 6 step768 adapter.

| Bucket | Examples |
|---|---:|
| TeamSync operations | 2,800 |
| Public general zh-TW conversations | 2,450 |
| Grounded semantic tasks | 1,050 |
| Paired tool/language boundaries | 700 |

Tool-oriented operations and boundaries together account for 50% of the corpus. General public dialogue accounts for 35% and grounded semantics for 15%. Each example initially has weight 1.0. The paired boundary subset contains 350 pairs, 400 legitimate tool-call targets and 300 no-call targets.

The compressed training file is identified by SHA-256 `9eaaef69d7b827c8996f5b565289b6def000b0c800d11dda1a32007373722d09`.

### Format

Each JSONL record carries input `messages`, offered `tools`, a separate assistant `target`, a stable example ID, family/source and mixture metadata, and `loss_weight`. Input history and tool results are context; the target is the supervised assistant continuation. Reproduction must preserve the publisher's native template and target mask boundaries.

### Provenance

TeamSync tasks and grounded semantic worlds are fictional assistant-authored simulations based on recorded tool contracts. Their tool results are fixtures, not live backend execution. Examples cover discovery, typed field values, grounded identifiers, reads, prepares, confirmation, conflict and result interpretation.

Public dialogue uses `yentinglin/twllm-data` revision `027f9f20c0d80d3695e1477c874ca9f102eccb68`. The publisher labels it Apache-2.0. Selected original-user subsets contain replacement answers generated by other language models; they are not independently verified human answers. Preserve [the publisher card](../licenses/TWLLM-README.md).

The release also retains the applicable [Glaive source notice](../licenses/Glaive-README.md) for its public replay component. Preserve per-record provenance and source attribution when repackaging the mixture.

No private LangSmith customer-derived record is included in this model's training corpus. Public-source pattern filtering removes known contact, identifier and credential formats but is not a certificate of anonymity or factual correctness.

Native template/schema checks covered all 7,000 examples and 700 boundary gold roundtrips. Exact train/dev prompt overlap was zero under the recorded check. This is corpus QA, not an independent language benchmark.

## Separately prepared corpus: 10,000 examples

This newer corpus was prepared for a follow-up run. Round 9 never reached an optimizer update in the observed attempts, so this corpus must not be described as the training data of the v0.1 model.

| Bucket | Examples | Share |
|---|---:|---:|
| TeamSync operations | 4,000 | 40% |
| Paired context/policy boundaries | 1,000 | 10% |
| Natural Taiwan Mandarin conversations | 4,000 | 40% |
| Grounded semantics | 1,000 | 10% |

Across the complete corpus, 3,500 targets call a tool and 1,500 dedicated tool scenarios teach a no-call response. Another 1,000 public conversations offer irrelevant tools while requiring a normal answer. Overall, 60% offer tools and 35% call one. These are overlapping measurements.

The public component includes 2,000 multi-turn conversations; 3,402 user-conversation signatures were not present in the v0.1 public subset. The underlying public source remains TWLLM.

The compressed training file has SHA-256 `8db18ac216bede4c1ab08c96e9499d8c85ce1ff26c0210c086778a0c9bd493b3`.

Its audited schedule requires a single process, sequential sampling, microbatch 1, accumulation 8 and mean target-token cross-entropy within each equally weighted example. Each update contains four dedicated tool scenarios. The first 512 updates present 4,096 examples: 2,048 tool scenarios, 1,638 public conversations and 410 semantic examples. A full epoch would require 1,250 updates.

## Excluded sources and evaluation separation

`TaiwanChat` carries CC-BY-NC-4.0 and was excluded from this intended permissive release mixture. The checked official Breeze sources did not provide a complete usable SFT corpus. Checked TAIDE resources included evaluation, gated and noncommercial materials; those were not substituted for training data. zh-TW BFCL and other benchmark test material are evaluation resources, not SFT examples.

Public training assets should contain the filtered training file, data card, provenance and source notices. Keep frozen validation/test labels outside the public training package. This release does not assign one new blanket license to all third-party data components.
