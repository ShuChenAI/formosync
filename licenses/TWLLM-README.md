# TWLLM-Data: Open Traditional Mandarin LLM Conversations

TWLLM-Data is the first large-scale open dataset containing real user-generated conversation logs from [TWLLM](https://www.twllm.com) and [TWLLM Arena](http://arena.twllm.com), where over 80% of users are based in Taiwan. The dataset is designed to facilitate the development and evaluation of Traditional Mandarin Large Language Models (LLMs).

We extend our gratitude to Professor Yun-Nung (Vivian) Chen for her guidance and advisement. 
Special thanks to Tzu-Han Lin, Kang-Chieh Chen, and Chang-Sheng Kao for synthetic data generation and refining.

## Dataset Overview

- **Source**: User interactions from TWLLM logs.
- **Size**: ~25K conversations.
- **Format**: `parquet` (JSON-like structured dialogues).
- **Languages**: Traditional Mandarin (`zh-TW`).
- **License**: [Apache 2.0](https://www.apache.org/licenses/LICENSE-2.0).

### Data Collection & Processing

1. **Real User Prompts**: Extracted from **twllm.com** and **arena.twllm.com** logs, ensuring authentic Taiwanese user input.
2. **Model Response Replacement**: The original model responses were removed and replaced with high-quality answers generated by **Gemini, Claude, or ChatGPT**.
3. **Synthetic Prompting Subsets**:
   - `twllm-evol` and `twllm-synthetic`: Prompts generated using evol-instruct-style transformations.

This dataset is intended for research in **fine-tuning Traditional Mandarin LLMs** and **understanding real-world user queries**.
